## Supporting explanation and applicability

Ashby hosts job boards at jobs.ashbyhq.com followed by the organization's slug, which the organization can change. Ashby also documents embedding the board in an external careers page and an API option in which candidates see the employer's own careers address instead of the Ashby-hosted page. A jobs.ashbyhq.com address identifies Ashby hosting. An employer address does not exclude Ashby. Treat the address as a dated observation of hosting and verify current documentation before relying on an exact format.
