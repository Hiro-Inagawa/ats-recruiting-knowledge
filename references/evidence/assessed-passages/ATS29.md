## Supporting explanation and applicability

Every published Lever posting is also visible on the Lever-hosted job site at jobs.lever.co followed by the account's site name. Hosted posting pages add a posting identifier, the application form adds /apply, and the EU environment uses jobs.eu.lever.co. The same documentation describes a public postings API often used to build a custom jobs page, so an employer address does not exclude Lever. Treat the address as a dated observation of hosting and verify current documentation before relying on an exact format.
