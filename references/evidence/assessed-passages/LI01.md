# LI01: Skills filter and Skills Match

Author/publisher: LinkedIn.

Publication/update metadata: 2 years ago. Relative publisher labels are not converted to an invented exact date. Source context captured 2026-10-02.

Evidence type: Official product documentation.

Original source: [Skills filter and Skills Match](https://www.linkedin.com/help/recruiter/answer/a593591).

## Supporting explanation and applicability

LinkedIn describes skill discovery using explicitly listed skills, profile text, opted-in résumé data and inferred related evidence. A keyword recognized as a skill may also use these sources. Its applicant Skills Match description relates skills and geographic conditions to a particular posted job, not to a universal ATS score. Explicitly listing a truthful skill can clarify evidence, but the documentation contradicts the assertion that only the Skills section can ever satisfy discovery. A returned or inferred skill is not proof of mastery, production experience or ranking weight.
