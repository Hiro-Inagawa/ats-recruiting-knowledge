# ATS & Recruiting Knowledge

A text-based skill for understanding recruiter operations, applicant implications, ATS mechanisms and LinkedIn discovery. It contains developed explanations, decision workflows, completed hypothetical records, a connected recruiting case and local supporting evidence explanations.

Start with [SKILL.md](SKILL.md) for assistant behavior, the [topic map](references/topic-map.md) for a question, or the [reading routes](references/reading-routes.md) for a sequence. The package preserves Chapters 1–16, recruiter subjects R1–R9 and workflows A–Q. Assessments use the [assessment method](references/assessment-method.md) to distinguish consequential corrections from evidence gaps and optional preferences.

## Local use

Install the whole folder as `ats-recruiting-knowledge` in the skill directory supported by your Codex or Claude Code application. Keep the relative file structure intact. Invoke `$ats-recruiting-knowledge` in Codex or `/ats-recruiting-knowledge` in Claude Code. Automatic activation is declared in the skill description and Codex UI metadata. The assistant reads relevant files before giving substantive advice; no hosted service or separate source workspace is needed.

The knowledge explains documented mechanisms and conditional reasoning. Exact interface operations, enabled features, platform rules and applicable law require a current check before operational reliance. Supporting URLs identify origins and refresh routes; they are not necessary to read the local explanations. A request for advice or assessment does not itself authorize applications, messages, uploads, edits or employer-system actions.

## Maintain the knowledge

Update an owning explanation and its supporting evidence together. Repair affected workflows and navigation. Review changed claims and run relevant checks. Verify application retrieval when behavior changes. Keep revision, acquisition and acceptance records outside the distributed skill. Historical editions are evidence, not competing current sources.
